# Contributing

Thanks for contributing to Test1. These notes provide a lightweight starting point; update them as the project adopts specific tools and checks.

## Changes

- Keep each change focused and describe its purpose in the pull request.
- Update documentation when behavior or setup changes.
- Run the checks relevant to your change and include the results in the pull request.

## Pull requests

1. Create a branch for your change.
2. Make and review your edits.
3. Open a pull request with a concise summary and any relevant testing notes.
